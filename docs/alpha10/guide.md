# alpha.10 — テスター報告への対応

## 変更点

| 報告 | 対応 |
| --- | --- |
| 難読地名・住所 (#1) | alpha.9の標準住所・地名辞書と19パックを継承。豊饒・雑餉隈・郵便番号の回帰検証を継続。辞書を再取得する必要はありません。 |
| Backspace後の候補窓 (#2) | 削除操作で候補窓を閉じ、次の入力や候補選択時に再表示。空候補・確定・フォーカス喪失でも閉じます。文字列編集に失敗しても古い窓を残しません。 |
| 確定済み文章のAPI変換 (#3) | 選択範囲の読み取りと変換開始を一つの編集処理に変更。取得できない場合は案内を表示。設定に「貼り付けて変換」を追加。 |
| 記号の幅 (#4) | 設定 → 全般 → 入力で「括弧」「カンマ・ピリオド」「その他の記号」を個別に半角指定。既存の全角動作が初期値。 |
| 候補番号の折り返し (#5) | 番号を縮まない列にし、2桁・3桁でも横書きを維持。表示サイズをWindowsの画面倍率に合わせます。 |
| テンキー (#6) | 「テンキーを常に半角で入力」を追加。数字、小数点、演算子に適用。上段の数字・NumLockオフの移動キーには適用しません。 |
| 英字混在 (#7) | 元のASCIIつづりを候補に保存。Google・Excelなど30語の綴り補助と、日本語に混在した候補を追加。通常の日本語の第一候補を優先。 |

半角を指定した記号・テンキー入力は、その前の入力文を確定してから直接挿入します。予測変換で全角へ戻りません。新しい設定は初期状態ではすべてオフです。

## いい感じ変換

- 入力中、または文章を選択して Ctrl + Shift + J。Enterで確定、Escで復元。
- Excelは **F2でセルを編集し、セル内の文字列を選択**してください。セル自体や複数セルの選択は直接変換の対象外です。
- ショートカットが利用できないアプリは、設定 → いい感じ変換 → **貼り付けて変換**。対象文を貼り、変換ボタンを押し、使う候補をコピーして元のアプリへ貼り付けます。
- 貼り付け欄は保存済みの接続設定を使用します。送信は明示的な変換操作のみ。クリップボードの自動取得・置換、自動貼り付けは行いません。
- Windows実機のExcel/Discord互換性は、テスターによる確認が必要です。CIの変換試験を実機アプリ試験として扱いません。

## 英字候補の範囲

任意の英語を意味から推測する機能ではありません。元のつづりの保持と、一般的な製品名30語の綴り補助です。日本語の途中でも候補を選べます。最大128入力文字までで、追加候補生成にはZenzai/APIを呼びません。補助候補は日本語学習辞書に誤った読みとして登録しません。

## Windows実機で確認する項目

1. 旧版の設定と辞書を残して上書きインストール。入力先アプリを再起動。
2. `nihongo`で日本語を入力。Spaceで候補を開き、Backspaceで削除。窓が消え、再入力すると現在の候補が出ること。
3. 10番目以降の候補へ移動。表示倍率100%・150%・200%で番号が横書きになること。
4. 各半角設定のオン/オフを比較。`()`、`[]`、`,`、`.`、`+`、`-`を入力。文章の途中でも確認。
5. テンキーの `123.45+6/2`。上段の数字、NumLockオフの移動、Alt＋テンキーを別途確認。
6. `Google`、`google`、`Googledenihongo`、`nihongodeGoogle`、`Exceldekeisann`、任意の英字を入力。選択・確定・Backspace・次の日本語入力を確認。
7. ChromeとExcelのセル内編集で確定済み文を選択しAPI変換。EnterとEscを確認。利用できない入力欄は貼り付け変換を確認。
8. 豊饒、雑餉隈、`100-0001`、追加辞書の既存語、Zenzai有効/無効を確認。

障害が出た場合は、設定 → 全般 → 診断ZIPを書き出す。入力文やAPIキーを含む画面を共有する必要はありません。
