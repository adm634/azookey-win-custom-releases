## 検証の限界

- CIはWindowsの実プロセスとインストール済みファイルを検証しますが、テスターのExcel・Discord上での入力操作を再現したものではありません。
- Excelのセル全体選択は直接変換の対象外です。F2のセル内編集、または貼り付け変換を使ってください。
- 英字補助は元のASCIIつづりと30語の一般的な名称です。意味から任意の英文を復元するものではありません。
- Vulkan/CUDAの各GPU性能、Windowsの画面倍率ごとの実表示はユーザー環境で確認が必要です。
- 旧版の設定・個人辞書・学習・追加辞書は保持します。新しい半角設定は初期状態ですべてオフです。
