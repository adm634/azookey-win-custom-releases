# alpha.8 辞書改修・検証報告

2026年9月25日。対象は辞書データ、辞書検索、追加辞書の配布・更新管理です。

標準搭載する住所・郵便番号パックは約8.6MBです。ほかは設定の「ユーザー辞書 → 追加辞書 → 一覧・更新を確認」で必要な分だけ取得できます。

## できること

- 「ぶにょう → 豊饒」「おおいたけんおおいたしぶにょう → 大分県大分市豊饒」。住所を含む文章でも追加語を使います。
- 「8700855」「870-0855」と全角数字から住所候補を表示。
- 地名、姓名・人物名、ブランドなどの固有名詞、登録読みのある法人名を追加。
- パックごとの取得・更新・有効無効・削除。個人辞書・学習データは保持。
- 20文字以内のかなで一致する追加語は、後方の同音候補を選んだ場合も学習。48候補の最後尾を選択し、変換エンジンを新しく起動して先頭へ昇格することをMacで確認。
- アプリ本体とは独立した辞書更新。取得後の変換はオフラインで動作し、辞書の取得・更新時にも入力文章を送信しません。

## 品質調整と実測

### 変換の品質

追加語を強く優先した試作では、普通の文章が地名・法人名へ変わる悪化を確認しました。基本優先度を下げ、長い正式住所のみ強める方式へ修正しています。

再ビルドした配布ファイルをMacの実変換エンジンで評価しました（Zenzai無効）。

- 通常文40例＋固有名詞・住所10例、追加なし／住所のみ／全6辞書で計150変換。
- 住所のみ・全6辞書とも、通常文40例の先頭候補が追加前と40/40一致。
- 豊饒、全文住所、住所を含む文章は先頭候補へ。
- 適格請求書は2位から1位、正式法人名2例は3位へ追加。
- 配布ファイルのSHA-256を評価前後で照合。

有限の例による回帰確認であり、すべての文章やWindows/Zenzaiで同じ順位を保証する評価ではありません。

### 容量・検索速度・メモリ

FSTという圧縮索引を常駐させ、候補データはページ単位で圧縮・暗号化。必要なページだけ復号します。

全6辞書を使うMac（Apple M5・メモリ16GB）の辞書検索ベンチマークでは、索引約52.8MB、通常時の検索p95約0.66ms。別のメモリ測定では最大常駐メモリ125.1MiBでした。これは辞書検索プログラム単体の値で、Windowsの変換全体やZenzaiモデルを含む数値ではありません。

### 更新・破損・競合

- パック契約テスト13件、別プロセス競合テスト5件がMacで成功。
- 暗号化データの破損、途中切れ、索引の不整合、サイズ上限、SHA不一致を拒否。
- 更新失敗で旧版を保持。旧版を使用中でも新しい版を別ファイルへ配置。
- OSファイルロックで設定アプリとサーバーの同時操作を調停。
- 無効化状態・削除状態を再起動後も維持。壊れた設定ファイルで辞書を削除しないことを確認。

## 出典・制限

- 日本郵便の全国住所、国税庁の法人番号公表データ（2026-08-31）、SudachiDict Full（20260723）を加工。
- 原資料の登録読みを使用。読みをAIで推測していません。上流の誤りや本人固有の読みまで保証はできません。
- 日本郵便の範囲指定を一意に解釈できない21行に相当する15郵便番号、大口事業所の個別番号、読み未登録の法人は未収録。
- 普通名詞・専門語候補は業界監修済み専門辞書ではありません。医療・法律等の分野別辞書は今後の別パックです。
- 同じ読みの全文候補は合計最大2,048。文章の分割探索は各読み32件、変換エンジンへ渡す集合は合計2,048件に制限。
- 郵便番号や20字超などの全文一致補完は、通常の学習候補とは別の経路です。
- 暗号化は安易なコピーの抑止です。完全な抽出防止ではなく、元データの利用条件・再利用権を上書きしません。
- 更新はパック単位。差分パッチ配信はこの版には含めません。
- 候補窓、記号幅、テンキー、英文混在、いい感じ変換のアプリ差といった別issueは対象外。
