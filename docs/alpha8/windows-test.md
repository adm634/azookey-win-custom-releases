# alpha.8 Windows確認手順

## 更新

1. 編集中の文書を保存し、azooKeyを使っているアプリを閉じます。
2. [alpha.8 のリリース](https://github.com/adm634/azookey-win-custom-releases/releases/tag/v0.1.0-alpha.8)から`azookey-setup.exe`を取得し、上書きインストールします。
3. 更新後にWindowsを再起動します。個人辞書と学習データは保持されます。

## 追加辞書

1. 設定の「ユーザー辞書 → 追加辞書 → 一覧・更新を確認」を開きます。
2. 必要な分野の「出典・利用条件」を確認し、「取得する」を押します。
3. 法人名辞書を取得したら「とよたじどうしゃ」で「トヨタ自動車株式会社」を探します。
4. 使いたい姓名の表記を候補から選び、次の入力で順位が学習されるかを確認します。
5. 必要なら無効化して普段の文章と比較します。既に学習した候補や他の辞書にある語は、無効化後も残る場合があります。

取得・更新はパック単位です。全種類を入れる必要はありません。法人名は同音候補が多いため、必要な場合に追加する使い方が向いています。

## 普段使うアプリ

メモ帳に加え、業務で使うアプリで通常入力、連続入力、Backspace、候補選択、確定を確認します。Windows CIの検証と、Discord・Excelなどの実機操作は別です。

不具合を報告する場合は、再現できる短い入力例、アプリ名、Zenzaiの有効無効・モデル・GPU設定、有効にした追加辞書を記録してください。実際の業務文書や個人情報を送る必要はありません。

クラッシュ時は「全般 → 診断ZIPを書き出す」から診断ZIPを作成できます。入力本文、APIキー、辞書の登録語は収集しません。
