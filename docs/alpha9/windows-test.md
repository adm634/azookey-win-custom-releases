# alpha.9 Windows確認手順

1. 作業を保存して上書きインストールし、Windowsを再起動します。
2. 「ユーザー辞書 → 追加辞書」で「住所・郵便番号」と「地名」が有効であることを確認します。
3. メモ帳で「ざっしょのくま」「ふくおかけんふくおかしざっしょのくま」「ざっしょのくまえき」を入力し、それぞれ「雑餉隈」「福岡県福岡市雑餉隈」「雑餉隈駅」が出るか確認します。
4. 「1000001」「100-0001」「１０００００１」「１００－０００１」で、先頭が「100-0001 東京都千代田区千代田」になることと、確定後に読みが残らないことを確認します。住所だけの候補も選択できます。
5. 必要な追加パックを取得します。法律は「しんたくじゅえきけん → 信託受益権」、医学は「じょうみゃくどうけっせん → 静脈洞血栓」などで候補を確認します。
6. 普段の文章を続けて入力し、候補選択・Backspace・再入力・アプリ切替を試してください。Discord、Chrome、Excelも日常の範囲で確認してください。
7. 不具合時はバージョン、入力例、使用アプリ、ZenzaiのON/OFFとモデル・バックエンド、追加パックの種類を添えてください。診断ZIPは設定の「全般」から書き出せます。業務上の機密文は報告に含めないでください。

入力語が候補にあることと、自然な文章の先頭候補になることは別の検査です。読み・表記・候補順位のどれに問題があるか分かる形で記録すると調査しやすくなります。
