# alpha.9 辞書拡充・検証記録

## 変更

- 標準搭載を「住所・郵便番号」と「地名」の2パックへ拡大。「雑餉隈」のために別途取得する必要がなくなりました。
- 郵便番号の先頭候補は「100-0001 東京都千代田区千代田」。住所だけの候補も選べます。
- 13パックを追加し、全19パック、10,089,364組の読み・表記を配布。パック間の重複を含む合計です。
- NEologd、UT人名、SKK、JMdict、JMnedict、DMiMEの出典・ライセンス・原本と編集可能データ・生成コードを公開。
- 追加語のコストは原則-14。SKK一般語の表記揺れを-16に抑え、通常文の「待ち合わせ」が「待合」に変わる回帰を修正。

- 辞書モジュール: 20テスト成功、プロセス補助用1件は通常実行では除外。

- 配布対応ソース単体の依存固定ビルドチェック成功。
- Macの実変換エンジンで、基本辞書のみ・標準2パック・全19パックの3構成×58入力＝174回を比較。
- 40通常文の先頭候補は、標準2パックと全19パックの両方で40/40が基本辞書と一致。

## 範囲・制限

Macの品質比較はZenzai・予測・学習OFF。Windows自動テストの実行結果と、ユーザーによるWindows各アプリの操作検証を区別します。
有限の文章と語例の検査であり、全語の正確さや全アプリの安全性、Google日本語入力と同じ網羅性を保証しません。
NEologd部分は2020年のデータです。原本の誤記・古い名称・誤読の可能性は残ります。
住所・地名以外の17パックは必要なものを利用者が取得する方式です。全19パックを初期ダウンロードさせる変更ではありません。
