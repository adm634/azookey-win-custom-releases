# alpha.9 辞書拡充

## 利用者向け変更

- 日本郵便の住所・郵便番号に加え、Sudachi由来の地名パックを標準搭載。
  「ざっしょのくま → 雑餉隈」は従来も任意パックに収録されていましたが、alpha.9では別途取得が不要です。
- 郵便番号の第一候補は `100-0001 東京都千代田区千代田`。
  ハイフンなし・全角数字でも、候補内の番号は半角とハイフンに統一。住所だけの候補も残します。
- 新規13パックを任意追加。設定の「ユーザー辞書 → 追加辞書」で用途に合うものを取得してください。
- alpha.8の住所導入済み記録がある環境にも、地名を一度だけ追加します。
  登録済み地名パックの無効状態は維持。標準パックとして導入後に削除したものは復活させません。
  alpha.8時点の任意地名パックの削除は記録されていなかったため、以前削除していてもalpha.9初回には導入されます。

JMdict/JMnedictは[scriptin/jmdict-simplified](https://github.com/scriptin/jmdict-simplified/releases/tag/3.6.2%2B20260921173324)のJSON配布を利用。原権利者はEDRDGと寄稿者です。原本の表記・読み制約と、名詞として有効な語義の制約を照合し、対応しない表記と読みを掛け合わせません。意味文・翻訳・例文はパックに収録しません。

データ件数は読みと表記の組み合わせです。同じ語を複数パックが含むため、合計は固有語彙数ではありません。NEologdは2020年のデータで、最新の流行語辞典とは呼べません。公開元に由来する誤読・誤記の可能性は残ります。

## 取り込み基準

- 配布条件と原本を確認し、SHA-256とサイズを固定。
- 名詞、またはSKKの送り仮名を伴わない静的候補に限定。
- 読みをNFKCとひらがなへ正規化。推測による読みは生成しません。
- 読み2〜100文字、表記2〜100文字。制御文字、不正な読みを除外。
- 基本辞書との完全重複、および各パック内の重複を除外。
- NEologdの伏字記号を含む表記と、点検で見つかった「じんこうちのう→人口知能」を除外。
- SKKのLisp・動的処理・送り仮名ブロック・数値展開を実行しません。注釈は候補から除去。
- JMdictの検索専用・不規則表記、古語・廃語の語義を除外。名詞語義の分野により一般・科学等・医学へ分類。
- 一般追加語のスコアは-14を維持。表記揺れの多いSKK一般語は-16とし、「待ち合わせ」が「待合」へ置き換わる回帰を抑えます。元辞書の頻度コストを混ぜません。

## 今回採用しなかったもの

- SKK wrong/wrong.annotated（誤読修正用）、送り仮名あり活用、動的式、略語展開。これらを名詞として投入すると誤候補になります。
- NEologdの活用語・日付数量自動展開。独立した名詞辞書の形式に合わないため。
- 万病辞書の全件自動読み、ComeJisyoの登録フォームを要する原本、利用条件と原本を確定できなかった生命科学辞書等。今回はDMiME/JMdictで医学語を補います。
- Wikipedia全記事からの自動読み生成、企業サイト等の無差別収集、商用IMEの辞書抽出、再配布許諾のない公開ファイル。
- 既存Sudachiや採用済み原本を束ねただけの混合辞書。重複配布と条件の混同を避けます。

「ウェブ上のあらゆる辞書を完全収録」や「Google日本語入力と同じ網羅性」を保証するものではありません。

## 再現と更新

`expansion-sources.json` が原本URL・サイズ・SHA-256の固定記録です。原本を取得して照合した後、次を実行します。

```
python3 dictionaries/scripts/build_expansion.py --raw RAW --base-dictionary BASE/Dictionary --output MATERIALS
python3 -m unittest discover -s dictionaries/scripts -p test_expansion.py -v
cargo build -p dictionary-packs --release --bin pack-tool
python3 dictionaries/scripts/package_expansion.py --raw RAW --materials MATERIALS --output PACKS --tool target/release/pack-tool
```

Windowsでは日本語ファイルの文字コードを固定するため`python -X utf8`を使い、実行ファイル名は`pack-tool.exe`にします。基本辞書はalpha.8と同じ固定版が必要です。対応ソース配布には生成済みTSVも含まれるため、基本辞書なしでTSVから再パッケージできます。暗号化nonceが毎回異なるため、再生成パックのバイナリハッシュは変わります。素材TSVのハッシュと件数を照合してください。

更新時は原本の最新公開版と利用条件を再確認し、新版番号・SHA-256へ明示的に更新、再生成、読み照合、通常文回帰・ネイティブWindows検証を経て公開します。EDRDGは各辞書更新リリース前に新しいスナップショットへ更新します。過去の不変版を上書きしません。現行アプリは公開カタログから利用者操作で追加・更新できます。

原本・生成済み編集可能TSV・出典・ライセンス・生成コード・パック読書きコードを同じ辞書リリースで公開します。GPL/CCの原条件は継承し、パック暗号化を再利用禁止の根拠にはしません。
